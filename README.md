# SiPinjam

A laboratory equipment borrowing and inventory management system that lets users request equipment loans while admins track and approve requests through a secure, role-based interface.

## Features
- Role-based routing (admin/user flows)
- Row-Level Security (RLS) policies for data access control
- Three-table schema: `profiles`, `items`, `loans`
- Equipment loan request and tracking workflow

## Tech Stack
- **Frontend:** Flutter (Nylo framework)
- **Backend/DB:** Supabase (PostgreSQL, RLS)

## Context
Developed as a final project for the D3 Mobile Programming course at Politeknik Negeri Pontianak.
